The JRC-FPD v2.0 JRC-FP dataset (version 2026) is available the following URL: https://data.jrc.ec.europa.eu/dataset/ae77d0b5-1932-4875-be06-a66a051db62f.  
The dataset is part of the JRC-Farming-Practices data collection – An evidence library of the effects of Farming Practices on the environment and the climate, available at: https://data.jrc.ec.europa.eu/collection/id-00399.

This repository contains the scripts and dataset to farming practices dataset version 2.0.
